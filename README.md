# ecomnex-instagram

Bilder und Vorlagen für den Instagram-Account von EcomNex.

- `posts/` enthält pro Post einen Ordner mit den Slides als JPG und den Texten als JSON.
- `vorlage/` enthält das Skript, das aus einer JSON-Datei die Slides baut, und das Logo.
- `warteschlange/` enthält fertig vorbereitete Posts, die als Nächstes an der Reihe sind.
- `log.json` listet alle Posts mit Datum, Format und Thema.
